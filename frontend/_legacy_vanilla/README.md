# Legacy vanilla frontend (archived)

These are the original **plain HTML/JS/CSS** frontend files, kept only for reference.
They were **fully replaced** by the React + Vite app in `frontend/src/` (built to
`frontend/dist/`, served by Express in production).

Nothing here is used by the dev server (`npm run dev`) or the production build
(`npm run build`). This whole folder is safe to delete once you no longer need it.
